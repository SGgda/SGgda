## What I've Built

### 🧠 MarketPulse — Stock Intelligence Platform
> *Databricks · PySpark · Delta Lake · FastAPI · React*

A real-time stock intelligence system built on the **Bronze → Silver → Gold medallion architecture**. Ingests live data for 6 tickers (RELIANCE.NS, TCS.NS, INFY.NS, AAPL, NVDA, MSFT) via yfinance, Reddit (PRAW), and NewsAPI. Silver layer computes **RSI, MACD, and Bollinger Bands** using `pandas_ta`. Built to demonstrate that a student can architect at the same level as a data engineer at a unicorn.

`Delta Lake` `Databricks Workflows` `PySpark` `FastAPI` `Recharts`

### 🐳 Docker DevOps MCP Server — *Published on npm*
> *Node.js · MCP Protocol · Docker SDK*

An **npm-published MCP (Model Context Protocol) server** that gives AI assistants like Claude real-time control over Docker containers — inspect, start, stop, stream logs, analyze health. The kind of tool that bridges the gap between natural language and DevOps infrastructure.

[**→ View on npm**](https://www.npmjs.com/package/docker-devops-mcp-server)

`MCP Protocol` `Docker SDK` `Node.js` `npm`

### 🏥 Journal App — Production-Grade Spring Boot System
> *Spring Boot · AWS EKS · Terraform · Redis · Supabase*

Not a CRUD tutorial. Containerized with Docker, pushed to ECR, deployed under deadline pressure for a professor presentation — and it worked.
